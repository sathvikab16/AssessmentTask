# AssessmentTask

A full-stack Task Management Application developed as part of an assessment project.

## 🔗 Live Demo

👉 https://assessment-task-alpha.vercel.app


## 📌 Project Overview

AssessmentTask is a web-based task management application that allows users to view and manage tasks through a simple and user-friendly interface.

The application includes a login page and a dashboard with navigation to different sections of the system.

## ✨ Features

- 🔐 Login page
- 📊 Dashboard
- 📋 Task management
- 📌 Task board
- 👥 Users section
- ⚙️ Settings section
- 📱 Responsive user interface
- 🔗 Frontend and backend integration
- 🌐 Deployed application

## 🖥️ Application Pages

### Login

The application opens with the login page.

### Dashboard

The dashboard provides an overview of the task management system, including:

- Total Tasks
- To Do
- In Progress

### Tasks

The Tasks section allows users to view and manage tasks.

### Board

The Board section provides a visual representation of tasks and their status.

### Users

The Users section provides user-related information.

### Settings

The Settings section provides application settings.
